提示詞工程指南：
LLM 溝通與結構化輸出實戰

掌握 Prompt Engineering 的四大核心原則，學習如何精確控制大型語言模型（LLM）的回答風格、格式與邏輯推理能力。

在生成式 AI 當道的時代，Prompt Engineering（提示詞工程）已成為與 AI 協作最重要的核心技能。精確的提示詞能大幅降低模型的幻覺（Hallucination），並確保產出的內容符合預期格式。

「好 Prompt 的關鍵不在於字數多寡，而在於提供『足夠的情境』與『清晰的輸出結構』。」

高質量 Prompt 的四大核心要素

1. 角色設定 (Role)

明確指定 AI 的專業身份，例如：「你是一位資深的前端架構師...」。

2. 背景情境 (Context)

說明任務發生的前提、目標受眾與限制條件，減少 AI 盲目發揮。

3. 具體指令 (Instruction)

使用明確的動詞交代要做的事，並列出嚴格的否定條件（Must / Do not）。

4. 輸出格式 (Format)

指定輸出為 JSON、Markdown 表格或符合特定 CSS class 的 HTML。

實用技巧：Few-Shot Prompting (少樣本提示)

當您需要 AI 輸出特定風格或格式時，直接提供一至兩個「範例」比單純文字說明更有效：

# 提示詞範例

請將輸入的句子轉換為極簡摘要，格式如下：

輸入： 雖然今天下著大雨，但小明依然堅持去健身房運動了兩小時。
輸出： [天氣] 下雨｜[行動] 健身兩小時

輸入： 專案時程非常緊張，團隊決定本週加班完成核心 API 的開發。
輸出： [狀況] 時程緊迫｜[行動] 加班完成 API

常見注意事項

  • 避免模糊詞彙： 少用「寫一篇好文章」，改用「寫一篇 500 字內、針對初學者的觀點分析」。
  • 善用分隔符號： 使用 `---` 或 `"""` 將參考資料與指令開來，避免指令注入。
  • 引導思考步驟： 加入「請一步步思考（Chain of Thought）」可顯著提升複雜邏輯問題的正確率。
