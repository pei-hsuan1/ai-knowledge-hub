如何設計一份高效率的
AGENTS.md / CLAUDE.md

拆解專案開發規範的核心要素，了解如何撰寫能讓 AI 助手秒懂、精確執行且具備長期可擴充性的規範文件。

在與 AI（如 Claude, Cursor, ChatGPT）協作開發時，最常遇到的痛點是：「每次開啟新對話，AI 都會忘記之前的設計風格與檔案架構」。

建立 AGENTS.md 或 CLAUDE.md 就是為了解決這個問題——它是專案的「系統記憶體與行為指南」，讓 AI 在閱讀後能立刻掌握專案脈絡，精確產生符合規範的程式碼。

「好的 AGENTS.md 就像是一位資深前端架構師留下的工程手冊，讓接手的 AI 不會犯低級錯誤。」

AGENTS.md 的 5 大核心區塊

1. 專案目的與範疇 (Project Scope)

說明這個網站或系統是做什麼的、目標受眾是誰，以及採用的技術棧（如純 HTML + Tailwind CSS CDN，無需 Node.js 建置環境）。

2. 專案目錄結構 (Directory Structure)

使用清晰的樹狀結構圖標明 index.html、pages/、css/ 等檔案的相對位置，並指定新頁面應放在哪個資料夾。

3. 視覺風格與 UI 規範 (Design System / UI Rules)

明確標示配色方案（如背景 bg-[#fcfcfd]、標題黑 slate-900）、卡片樣式、標籤格式與字體大小，避免 AI 生成風格不一致的網頁。

4. 標準 HTML 頁面模板 (Template Architecture)

提供一份可以直接複製使用的基本 HTML 骨架，包含統一的 <header> 導覽列與 <footer> 頁腳，讓 AI 填入內容即可完成新頁面。

5. AI 操作行為規範與連鎖工作流 (Rules for AI)

定義嚴格的規則，例如：「新增文章頁面後，必須同步更新 index.html 的卡片索引」、「檔案命名必須使用 Kebab-case」等。

撰寫高效率規範的 3 個黃金法則

  • 使用具體 Class 名稱，取代模糊形容詞： 寫「卡片請用 rounded-2xl bg-white p-6 border border-slate-200/80 shadow-xs」，不要只寫「請做一個好看的卡片」。
  • 規範相對路徑規則： 特別強調 pages/ 目錄內的檔案需使用 ../index.html 引用根目錄資源，避免部署到 GitHub Pages 時連結失效。
  • 要求端到端自動更新 (Auto-indexing)： 要求 AI 不只產生單一頁面，還要把新頁面連回首頁，確保網站導覽體驗完整。

快速生成的 Prompt 範例

# 如何讓 AI 幫你草擬一份 AGENTS.md

"請根據我目前的專案結構與 UI 風格，寫一份 AGENTS.md 檔案。這份檔案需要包含專案目的、目錄結構、Tailwind 配色與卡片樣式規範，以及 AI 新增內容時必須遵守的命名與相對路徑規則。"
